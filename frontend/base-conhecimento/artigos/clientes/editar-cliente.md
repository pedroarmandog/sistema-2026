## Passo a Passo

### Passo 1: Localize o cliente

1. Acesse **Cliente > Meus Clientes**
2. Use a **pesquisa** para encontrar o cliente desejado
3. Clique sobre o cliente para abrir o perfil

### Passo 2: Edite as informações

1. Clique no botão **"Editar"**
2. Altere os campos necessários
3. Atualize telefone, endereço ou outras informações

### Passo 3: Salve as alterações

1. Clique em **"Salvar"** para confirmar
2. Os dados serão atualizados no sistema

---

## 💡 Dicas

- Mantenha os telefones sempre atualizados para o envio de mensagens
- Alterações no endereço podem ser feitas com busca de CEP
