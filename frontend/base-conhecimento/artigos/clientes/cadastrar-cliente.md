## Passo a Passo

### Passo 1: Acesse a tela de clientes

1. No menu lateral, clique em **Cliente > Novo Cliente**
2. O formulário de cadastro será exibido

### Passo 2: Preencha os dados do cliente

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| **Nome** | Sim | Nome completo do cliente |
| **Telefone** | Sim | Telefone para contato (WhatsApp) |
| **E-mail** | Não | Endereço de e-mail |
| **CPF/CNPJ** | Não | Documento do cliente |
| **Data de Nascimento** | Não | Para envio de aniversário automático |
| **Endereço** | Não | Logradouro, número, bairro, cidade, CEP |
| **Observações** | Não | Anotações sobre o cliente |

### Passo 3: Salve o cadastro

1. Revise as informações
2. Clique em **"Salvar"**
3. O cliente será cadastrado e estará disponível para agendamentos e vendas

---

## 💡 Dicas

- O campo **telefone** é usado para envio de mensagens automáticas
- Preencha a **data de nascimento** para ativar as mensagens de aniversário
- Utilize a **busca de CEP** para preencher o endereço automaticamente
