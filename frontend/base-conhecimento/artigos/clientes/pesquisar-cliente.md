## Passo a Passo

### Passo 1: Acesse a lista de clientes

1. Vá em **Cliente > Meus Clientes**
2. A lista completa de clientes será exibida

### Passo 2: Utilize a pesquisa

1. No campo de **busca**, digite o nome, telefone ou e-mail do cliente
2. A lista será filtrada automaticamente enquanto você digita
3. Os resultados exibem os clientes que correspondem à busca

### Passo 3: Filtros avançados

Utilize os filtros disponíveis para refinar a busca:
- **Grupo de cliente**: Filtre por grupo específico
- **Cidade**: Busque clientes de uma determinada cidade
- **Status**: Clientes ativos ou inativos

---

## 💡 Dicas

- A pesquisa funciona com **nomes parciais** — digite apenas parte do nome
- É possível buscar pelo **telefone** do cliente
- Use os **filtros** para encontrar grupos específicos de clientes
