# Como conectar o WhatsApp

Aprenda a conectar uma instância do WhatsApp Business no PetHub para disparo de mensagens.

⏱ **Tempo estimado:** 4 minutos
📊 **Nível:** Intermediário

## Passo a Passo

### Passo 1: Acesse o módulo de Marketing

1. No menu lateral, clique em **Marketing**
2. Acesse a seção **"WhatsApp"** ou **"Conexões"**

### Passo 2: Adicione uma nova instância

1. Clique em **"Nova Conexão"** ou **"Conectar WhatsApp"**
2. Dê um nome para a instância (ex: "WhatsApp PetShop")

### Passo 3: Escaneie o QR Code

1. Um **QR Code** será exibido na tela
2. Abra o WhatsApp no seu celular
3. Vá em **Menu > WhatsApp Web**
4. Escaneie o QR Code exibido no sistema

### Passo 4: Confirme a conexão

1. Após escanear, a instância será conectada
2. O status mudará para **"Conectado"**
3. Agora você pode enviar mensagens pelo sistema

---

## 💡 Dicas

- Mantenha o celular **conectado à internet** para manter a sessão ativa
- É possível conectar **múltiplas instâncias** para diferentes números
- A sessão pode ser **restaurada automaticamente** em caso de queda

---

## ⚠️ Atenção

- O WhatsApp **não pode ser usado** simultaneamente no celular e no sistema para o mesmo número
- A sessão pode **expirar** se o celular ficar muito tempo offline
- Utilize um **número dedicado** para o sistema se possível

---

## ❌ Erros Comuns

| Erro | Solução |
|------|---------|
| "QR Code expirado" | Gere um novo QR Code e escaneie novamente |
| "Conexão perdida" | Verifique se o celular está online |
| "Sessão desconectada" | Reconecte escaneando o QR Code novamente |
